# HuiCode Studio Web 化与任务平台 Checklist

> 每一项都必须通过运行测试、调用 API、观察 UI 或检查实际运行状态完成验证，不能仅凭代码存在判定通过。

## Implementation Completeness

- [ ] **C1 服务可启动**：使用开发配置启动 API，访问 `/health/live` 返回成功；数据库或 Redis 不可用时 `/health/ready` 返回不可用并指出依赖类型。（覆盖 AC10、AC15）
- [ ] **C2 配置安全**：使用生产模式但不提供 JWT secret 或数据库配置时，服务拒绝启动；日志不打印配置原值。（覆盖 AC15）
- [ ] **C3 数据库迁移**：对空数据库执行升级后生成全部核心表，对当前版本执行重复升级不产生错误；迁移失败时不会留下半完成版本。（覆盖 AC10）
- [ ] **C4 用户注册登录**：新用户可以注册、登录、刷新登录状态并退出；错误密码、失效 Token 和已禁用用户被拒绝。（覆盖 AC1）
- [ ] **C5 工作区初始化**：新用户注册后拥有默认工作区和 owner 身份，可以进入工作区首页。（覆盖 AC1）
- [ ] **C6 项目管理**：owner/admin 可以创建、重命名和归档项目；viewer 不能创建或修改项目。（覆盖 AC1、AC6、AC8）
- [ ] **C7 会话管理**：成员可以在有权限的项目中创建、重命名和恢复会话，历史会话按更新时间正确排列。（覆盖 AC2、AC4）
- [ ] **C8 Run 状态机**：Run 只能沿合法状态转换，非法转换返回稳定错误码且不修改数据库。（覆盖 AC2、AC5、AC11）
- [ ] **C9 Runtime 复用**：Web Worker 和 CLI 使用同一 Agent Loop、工具注册与权限语义；共享 contract test 对两种入口产生一致结果。（覆盖 AC9）
- [ ] **C10 时间线与 Diff**：完成写文件任务后可以查看完整时间线、工具摘要、修改文件列表和 Diff。（覆盖 AC7）
- [ ] **C11 审计与用量**：管理员可以查询任务次数、耗时、Token 和审批记录；普通成员不能修改审计或管理员数据。（覆盖 AC8）

## Authentication and Tenant Isolation

- [ ] **C12 API 身份校验**：未登录访问工作区、项目、会话、Run、Artifact 或审计接口均返回未认证。（覆盖 AC6）
- [ ] **C13 工作区隔离**：用户 A 使用页面和直接 API 请求均不能读取、修改或推测用户 B 工作区中的资源。（覆盖 AC6）
- [ ] **C14 关联资源隔离**：即使知道其他工作区的 session_id、run_id、approval_id 或 artifact_id，也不能通过子资源接口读取数据。（覆盖 AC6）
- [ ] **C15 角色边界**：viewer、member、admin 和 owner 的允许/拒绝行为与权限矩阵一致，拒绝操作进入审计日志。（覆盖 AC6、AC8）
- [ ] **C16 Token 安全**：过期、伪造、错误签名和已注销 refresh token 均不能换取有效身份。（覆盖 AC6）

## Agent Execution and Live Events

- [ ] **C17 创建 Run**：提交消息后 API 立即返回 run_id，Run 进入 queued，Worker 领取后进入 running。（覆盖 AC2）
- [ ] **C18 文本实时输出**：浏览器在任务完成前持续收到文本增量，不需要刷新页面；最终文本与持久化会话一致。（覆盖 AC2）
- [ ] **C19 工具生命周期**：工具开始、进度、结束和错误事件按 sequence 顺序展示，并能关联到同一个 tool_call_id。（覆盖 AC2、AC7）
- [ ] **C20 Usage 记录**：模型返回 usage 后，Run、时间线和管理员用量视图中的数字一致。（覆盖 AC2、AC8）
- [ ] **C21 事件单调顺序**：单个会话中的 sequence 唯一且单调递增，并发写入不会出现重复 sequence。（覆盖 AC2、AC4）
- [ ] **C22 断线补偿**：在任务运行中断开 SSE，再携带最后事件序号重连，缺失事件按顺序补齐且不重复。（覆盖 AC4）
- [ ] **C23 Redis 降级**：事件已经提交数据库但 Redis 发布失败时，重新连接仍能从数据库获取完整事件。（覆盖 AC4、AC12）
- [ ] **C24 页面刷新恢复**：任务运行中刷新页面，UI 恢复当前 Run 状态、已有文本、工具调用和待审批项。（覆盖 AC4）
- [ ] **C25 页面关闭不终止任务**：关闭浏览器后 Worker 继续运行；重新打开会话后可以看到最终状态和结果。（覆盖 AC4）

## Approval and Idempotency

- [ ] **C26 审批请求展示**：副作用工具执行前 UI 展示工具名称、目标资源、风险级别和摘要，工具在决定前没有执行。（覆盖 AC3）
- [ ] **C27 允许审批**：有权限用户允许后工具只执行一次，时间线记录审批人、决定和执行结果。（覆盖 AC3、AC13）
- [ ] **C28 拒绝审批**：用户拒绝后工具不执行，Agent 获得明确拒绝结果并安全结束或继续其他步骤。（覆盖 AC3）
- [ ] **C29 审批过期和越权**：过期审批、其他工作区用户和无权限角色提交决定均被拒绝。（覆盖 AC3、AC6）
- [ ] **C30 重复审批**：对同一 approval_id 重复提交相同或不同决定不会再次释放工具，返回已有决定或冲突。（覆盖 AC13）
- [ ] **C31 重复创建 Run**：使用同一 Idempotency-Key 重复提交消息，只产生一个 Run。（覆盖 AC13）
- [ ] **C32 重复 Tool Call**：同一 tool_call_id 被 Worker 重复处理时返回历史执行结果，不重复产生文件写入或外部副作用。（覆盖 AC13）
- [ ] **C33 重复取消和重试**：重复取消或重试请求返回稳定状态，不生成重复任务。（覆盖 AC5、AC13）

## Cancellation, Limits and Recovery

- [ ] **C34 用户取消**：取消运行中的任务后不再开始新的模型请求或工具调用，当前可终止执行被停止，Run 最终为 cancelled。（覆盖 AC5、AC11）
- [ ] **C35 等待审批时取消**：Run 等待审批时取消，审批进入 cancelled，后续提交允许决定也不能执行工具。（覆盖 AC5、AC13）
- [ ] **C36 Run 总超时**：超过最大 Run 时长后任务停止，时间线显示 timeout 错误码和最终状态。（覆盖 AC11）
- [ ] **C37 工具和 Shell 超时**：超时工具及其子进程树被终止，Worker 不持续占用任务。（覆盖 AC11、AC14）
- [ ] **C38 最大迭代限制**：Agent 达到最大迭代次数后停止，不继续请求模型，返回清晰的预算耗尽原因。（覆盖 AC11）
- [ ] **C39 最大调用限制**：达到工具调用上限后拒绝新工具，已有结果仍可在时间线查看。（覆盖 AC11）
- [ ] **C40 输出限制**：超大 stdout、stderr 或工具结果被截断并保存摘要，服务内存不因输出无限增长。（覆盖 AC11、AC14）
- [ ] **C41 Worker 心跳**：运行中的 Worker 按配置更新 lease；正常执行期间恢复扫描不会误领任务。（覆盖 AC12）
- [ ] **C42 Worker 崩溃恢复**：强制终止 Worker 后，过期 Run 进入 recovering 并产生恢复事件。（覆盖 AC12）
- [ ] **C43 安全重试**：没有不可逆副作用或具备幂等记录的任务可以被重新入队并完成。（覆盖 AC12）
- [ ] **C44 不安全重试保护**：无法证明安全的任务不会自动重放已完成副作用，而是进入失败或人工处理状态。（覆盖 AC12、AC13）
- [ ] **C45 服务重启恢复**：重启 API、Worker、Redis 后，持久化会话和事件仍可读取，Run 状态不无提示丢失。（覆盖 AC4、AC12）

## Security Boundaries

- [ ] **C46 路径穿越防护**：使用 `..`、绝对路径和编码变体访问 workspace 外路径均被拒绝。（覆盖 AC14）
- [ ] **C47 链接逃逸防护**：通过符号链接或 Windows junction 指向 workspace 外路径时，读写和 Shell 工作目录均被拒绝。（覆盖 AC14）
- [ ] **C48 项目根目录约束**：API 无法创建指向未授权宿主机路径的项目。（覆盖 AC6、AC14）
- [ ] **C49 工具能力声明**：只读、文件写入、Shell、网络和外部副作用工具均具有正确能力元数据，缺少声明的工具默认按高风险处理。（覆盖 AC3、AC14）
- [ ] **C50 Plan Mode 安全**：Plan Mode 下通过 Web 和 CLI 均不能执行写入、Shell 或其他副作用工具。（覆盖 AC9、AC14）
- [ ] **C51 危险命令拦截**：已有危险命令黑名单在 Web Worker 中继续生效，拒绝事件包含安全分类但不泄露内部配置。（覆盖 AC9、AC14）
- [ ] **C52 Shell 进程边界**：工作目录被限制在 workspace，环境变量按策略过滤，超时后整个子进程树退出。（覆盖 AC14）
- [ ] **C53 网络策略**：deny 模式阻止网络访问，allowlist 模式只允许配置目标，策略不能由普通 API 请求覆盖。（覆盖 AC14）
- [ ] **C54 前端不可绕过**：直接构造 API 请求跳过审批、权限、资源预算或执行后端选项时，服务端仍然拒绝。（覆盖 AC6、AC13、AC14）

## Sensitive Data Protection

- [ ] **C55 日志脱敏**：把测试 API key、Authorization、Cookie、Password 和 Token 写入请求及异常后，结构化日志仅出现脱敏值。（覆盖 AC15）
- [ ] **C56 事件脱敏**：工具输出和模型消息包含测试密钥时，SessionEvent payload 和 SSE 只包含脱敏值。（覆盖 AC15）
- [ ] **C57 存储脱敏**：数据库、审计记录、Artifact 元数据、Session 和 Memory 中不保存可由普通用户读取的密钥原文。（覆盖 AC7、AC15）
- [ ] **C58 API 响应脱敏**：错误响应、时间线、Diff、Artifact 和配置接口不返回敏感配置原文。（覆盖 AC7、AC15）
- [ ] **C59 内部事件可见性**：标记为 internal 的事件不推送给普通成员，管理员视图也只显示允许公开的摘要。（覆盖 AC6、AC15）

## Observability and Operations

- [ ] **C60 全链路关联**：使用一个 run_id 可以从 API 日志定位 Worker、模型调用、工具调用、审批、错误和最终结果。（覆盖 AC15）
- [ ] **C61 健康检查**：数据库、Redis 或 Worker 不健康时 readiness 反映真实依赖状态，liveness 不因暂时依赖故障误杀 API。（覆盖 AC15）
- [ ] **C62 结构化错误**：超时、取消、权限拒绝、路径违规、队列失败和 Provider 错误具有稳定错误码和用户可读提示。（覆盖 AC7、AC11、AC14、AC15）
- [ ] **C63 审计完整性**：登录、项目变更、Run 创建、审批、取消、恢复和管理员操作均留下带 actor、resource 和 request_id 的审计记录。（覆盖 AC8、AC12、AC15）
- [ ] **C64 备份恢复**：按照文档备份数据库和 Artifact，恢复到新环境后可以读取历史项目、会话、时间线和 Diff。（覆盖 AC4、AC10）
- [ ] **C65 故障 Runbook**：按照 Runbook 实际完成一次 Worker 崩溃恢复和一次 Redis 故障补偿，步骤与结果一致。（覆盖 AC12、AC15）

## Build and Automated Tests

- [ ] **C66 Python 编译检查**：运行 `python -m compileall huicode tests` 无语法错误。
- [ ] **C67 后端单元测试**：运行服务端单元测试全部通过，覆盖认证、角色、状态机、预算、脱敏和路径解析。
- [ ] **C68 后端集成测试**：使用真实 PostgreSQL 和 Redis 运行迁移、事件、Worker、审批和恢复测试全部通过。
- [ ] **C69 CLI 回归测试**：运行现有 HuiCode 全量测试无新增失败，CLI 启动、工具、权限、MCP、Skill、Subagent 和 Team 行为不回归。（覆盖 AC9）
- [ ] **C70 前端类型检查**：运行前端 TypeScript 类型检查无错误。
- [ ] **C71 前端单元测试**：运行认证、SSE Store、审批、时间线和 Diff 组件测试全部通过。
- [ ] **C72 前端构建**：运行生产构建成功且无缺失环境变量或循环依赖错误。
- [ ] **C73 数据库迁移测试**：在空库和已存在数据的旧版本数据库上执行升级均成功。
- [ ] **C74 CI 门禁**：CI 中的后端测试、前端测试、类型检查、迁移检查、构建和 E2E 均通过；故意引入失败时能够阻止合并。

## End-to-End Scenarios

- [ ] **E1 完整主流程**：注册/登录 → 创建工作区项目 → 创建会话 → 发起 Agent 任务 → 实时查看文本和工具事件 → 审批工具 → 查看最终结果和 Diff。（覆盖 AC1、AC2、AC3、AC7、AC10）
- [ ] **E2 拒绝流程**：发起会修改文件的任务 → 拒绝审批 → 文件保持不变 → 时间线显示拒绝和安全终止结果。（覆盖 AC3）
- [ ] **E3 断线恢复**：运行长任务 → 断开网络并刷新页面 → 重新登录和进入会话 → 补齐事件并看到正确最终结果。（覆盖 AC4）
- [ ] **E4 取消流程**：运行会启动长时间子进程的任务 → 点击取消 → 子进程树退出 → Run 显示 cancelled → 无后续工具执行。（覆盖 AC5、AC11）
- [ ] **E5 租户隔离**：创建两个用户和两个工作区 → 使用用户 A 的浏览器和 Token 尝试访问用户 B 的全部资源 → 页面和 API 均拒绝。（覆盖 AC6）
- [ ] **E6 Worker 崩溃恢复**：任务执行中终止 Worker → 等待租约过期 → 重启 Worker → 可安全任务恢复且副作用不重复。（覆盖 AC12、AC13）
- [ ] **E7 安全攻击场景**：依次尝试路径穿越、符号链接逃逸、危险命令、超时进程、超大输出和测试密钥泄露 → 所有行为被拒绝、终止或脱敏并留下审计记录。（覆盖 AC14、AC15）
- [ ] **E8 CLI 兼容场景**：在同一版本中启动原有 CLI，完成一次真实对话和工具调用，其权限、流式输出和会话恢复正常。（覆盖 AC9）
- [ ] **E9 重启持久化**：完成一次任务后停止全部 Compose 服务并重新启动 → 登录后仍可查看项目、会话、事件、审批、用量和 Diff。（覆盖 AC4、AC10、AC12）

## 学习与面试记录验收

- [ ] **L1 任务记录**：已完成的 T 任务均可在学习索引找到对应记录（允许紧密关联任务合并），记录含原理、取舍、代码和测试链接；逐项对照 task.md 检查。
- [ ] **L2 事实证据**：抽查工程问题记录能按命令复现或追溯验证结果；设计风险、注入故障和真实故障明确区分，未测量的指标未写成成果。
- [ ] **L3 动手学习**：每组记录提供可执行实验、小改动练习、自测问题和核对依据；选取每个里程碑至少一个实验按步骤验证。
- [ ] **L4 阶段复盘**：各已交付里程碑有端到端数据流说明、重要取舍、实际问题和遗留限制，并链接原始记录。
- [ ] **L5 面试真实性**：候选面试表达和简历条目均有实现证据；明确协作方式，用户理解状态未经反馈不标记已掌握。
