# Worktree 隔离验收清单

> 实施完成后逐项填写实际结果。未提供证据的项目不得标记通过。

## 一、配置与角色声明

- [x] **C1 默认配置可加载**：不配置 `worktrees` 时，程序得到安全默认根目录、期限、清理间隔和复制规则。
  **验证：** 运行配置单元测试并断言 `LLMConfig.worktrees` 的默认字段。

- [x] **C2 完整配置可加载**：根目录、过期期限、清理间隔、复制文件、链接目录、忽略文件恢复和 Hooks 来源均能从 YAML 读取。
  **验证：** 用完整 YAML fixture 加载并逐字段断言。

- [x] **C3 错误配置被拒绝**：绝对根目录、越界路径、非正期限、字段类型错误和重复规则给出明确配置错误。
  **验证：** 参数化配置测试逐项断言错误字段名。

- [x] **C4 角色隔离声明正确**：缺省及 `shared` 使用共享工作区，`worktree` 启用隔离，其他值在角色加载阶段失败。
  **验证：** 角色 parser/catalog 测试。对应 AC2。

- [x] **C5 Fork 行为不变**：Fork 请求没有 Worktree 开关，运行时不调用 WorktreeManager。
  **验证：** Runner mock 测试断言零调用。对应 AC2。

## 二、路径与清单安全

- [x] **C6 合法名称可嵌套**：允许字符范围内的单段和多段逻辑名映射到专用根目录内。
  **验证：** 命名表驱动测试检查规范绝对路径。对应 AC3。

- [x] **C7 路径逃逸被前置拦截**：`.`、`..`、空段、绝对路径、盘符、反斜杠、控制字符、超长和超深名称全部在 Git 或写文件前失败。
  **验证：** Fake Git/File Writer 调用计数保持 0。对应 AC3。

- [x] **C8 管理清单原子写入**：有效清单可往返读取，写入中断不产生可被接受的半截清单。
  **验证：** 清单原子替换与故障注入测试。

- [x] **C9 清单严格匹配**：格式版本、仓库、任务、逻辑名、路径、分支或基线任一不匹配均拒绝恢复。
  **验证：** 每字段篡改测试。对应 AC4。

- [x] **C10 已存在目录恢复零 Git 调用**：清单完全匹配时成功返回恢复句柄，整个恢复分支不调用任何 Git 方法。
  **验证：** 注入一经调用就抛错的 Git Backend，恢复仍成功。对应 AC4。

- [x] **C11 普通目录不会被接管**：目标目录存在但清单缺失、损坏或路径不匹配时明确拒绝。
  **验证：** Manager 恢复测试。对应 AC4、AC8。

## 三、Git Worktree 生命周期

- [x] **C12 Git 执行无 shell**：所有 Git 子进程使用参数数组、`shell=False` 和显式 `cwd`。
  **验证：** mock `subprocess.run` 检查每次调用参数。

- [x] **C13 从当前 HEAD 创建**：隔离分支基线等于任务启动时主仓库 HEAD。
  **验证：** 临时仓库比较两个 `rev-parse HEAD`。对应 AC1。

- [x] **C14 主工作区未提交修改不带入**：主目录修改已跟踪文件但不提交后创建 Worktree，隔离目录仍是 HEAD 内容。
  **验证：** 读取两处文件并比较。对应 AC1。

- [x] **C15 并行任务目录与分支唯一**：两个任务得到不同路径和不同任务分支。
  **验证：** 同一临时仓库并行 prepare 两个任务并断言。对应 AC1、AC6。

- [x] **C16 Worktree 修改不覆盖主目录**：隔离目录写文件后，主工作区同文件保持原值。
  **验证：** 真实文件读写对比。对应 AC1。

- [x] **C17 Hooks 为目标 Worktree 配置**：配置 Hooks 来源后，目标工作目录的 per-worktree `core.hooksPath` 指向预期位置。
  **验证：** 临时仓库读取目标 Worktree 配置。对应 AC5。

- [x] **C18 Git 错误可诊断**：Git 不可用、非仓库、分支冲突和命令超时返回包含操作名的结构化错误。
  **验证：** Backend 故障注入测试。对应 AC10。

## 四、环境初始化

- [x] **C19 本地配置复制正确**：存在的默认文件被复制，显式配置但不存在的文件报错，可选默认文件缺失可跳过。
  **验证：** 初始化器 fixture 对比源和目标。对应 AC5。

- [x] **C20 忽略文件按规则恢复**：文件与 glob 均保持相对目录结构，越界匹配被拒绝。
  **验证：** 多层 fixture 和越界 fixture。对应 AC5。

- [x] **C21 大型依赖使用目录链接**：链接目标指向主工作区目录，没有静默复制；平台不支持时返回明确错误。
  **验证：** 检查链接属性及目标，或验证平台错误。对应 AC5、AC10。

- [x] **C22 初始化失败会回滚**：任一步失败后子 Agent 不启动，刚创建的 Worktree 与任务分支被清理；回滚失败时目录保留并合并报告。
  **验证：** 每个初始化步骤故障注入并检查仓库状态。对应 AC5。

- [x] **C23 快速恢复不覆盖环境**：已有 Worktree 恢复时不再次复制、链接或配置 Hooks。
  **验证：** 修改目标配置文件后恢复，内容和时间戳保持不变。对应 AC5。

## 五、上下文与工具隔离

- [x] **C24 工具使用显式 Worktree cwd**：Read、Write、Edit、Find、Search 和 Bash 在隔离任务中都以 Worktree 为根。
  **验证：** Fake Provider 触发各工具，检查结果路径及 Bash cwd。对应 AC6。

- [x] **C25 全局当前目录不变化**：创建、进入、运行、退出和删除前后的 `Path.cwd()` 相同。
  **验证：** 生命周期集成测试前后断言。对应 AC6。

- [x] **C26 路径缓存不串线**：两个 Worktree 中同名文件、项目指令和记忆索引内容不同，加载结果始终对应各自绝对目录。
  **验证：** 双工作区缓存测试。对应 AC6。

- [x] **C27 Prompt 注入隔离说明**：隔离子 Agent 能看到准确绝对路径、分支、禁止修改主工作区及不自动合并说明；共享任务没有该块。
  **验证：** Prompt 快照或模块断言。对应 AC6。

- [x] **C28 权限与 Token 状态仍独立**：两个子 Agent 的权限上下文、文件读取缓存、消息和 Token 用量对象互不共享。
  **验证：** 并行 Runner 测试比较对象标识和结果。对应 AC6。

## 六、结束保护与结果回流

- [x] **C29 成功且干净自动删除**：最终回复正常、工作树干净且无未推送提交时，目录和任务分支被安全移除。
  **验证：** 完成场景检查文件系统和 `git worktree list`。对应 AC7。

- [x] **C30 未提交修改被保留**：任务成功但工作树 dirty 时目录保留，删除方法未调用，结果说明原因。
  **验证：** Runner/Manager 集成测试。对应 AC7、AC8。

- [x] **C31 无上游新提交被保留**：任务分支相对基线有提交但没有上游时判定为 unpushed。
  **验证：** 临时仓库提交后 finalize。对应 AC7、AC8。

- [x] **C32 有上游 ahead 提交被保留**：分支领先上游时判定为 unpushed，推送同步后允许安全删除。
  **验证：** 使用本地 bare 仓库充当远端。对应 AC7、AC8。

- [x] **C33 失败与取消被保留**：子 Agent 抛异常或收到取消时不删除目录。
  **验证：** 两种 Runner 场景检查处置状态。对应 AC7。

- [x] **C34 删除前再次校验身份**：清单被篡改、目标越界或仓库不匹配时删除拒绝，Git remove 未调用。
  **验证：** 删除前篡改 fixture。对应 AC8。

- [x] **C35 结果包含 Worktree 信息**：前台结果、后台任务详情和回流主 Agent 的结果包含路径、分支、状态与保留原因。
  **验证：** SubagentResult/TaskView/通知集成测试。对应 AC7。

- [x] **C36 隔离准备失败不降级**：prepare 失败时任务结束为明确失败，主工作区工具未执行。
  **验证：** Fake Manager 抛错并检查工具调用计数。对应 AC10。

## 七、过期清理

- [x] **C37 只清理可信候选**：只有位于专用根目录、清单有效且仓库归属正确的过期目录进入删除判断。
  **验证：** 混合候选目录测试。对应 AC9。

- [x] **C38 清理不跟随链接逃逸**：指向根目录外的目录链接或伪造路径被跳过。
  **验证：** 可创建链接的平台执行逃逸测试；不支持的平台验证安全拒绝。对应 AC9。

- [x] **C39 清理复用变更保护**：过期但 dirty、unpushed、失败保留中的目录不删除。
  **验证：** Cleanup 调用真实 Manager 保护测试。对应 AC9。

- [x] **C40 单项失败不影响扫描**：一个候选报错后后续安全候选仍会处理，每项都有记录。
  **验证：** 第一个候选故障注入，断言第二个完成。对应 AC9。

- [x] **C41 后台线程可关闭**：启动扫描、周期扫描和关闭不会阻塞 CLI，也不会在关闭后继续处理候选。
  **验证：** 短间隔线程测试和 join 超时断言。对应 AC9。

## 八、端到端与回归

- [x] **C42 端到端隔离修改**：真实临时 Git 仓库中，定义式子 Agent 通过工具修改 Worktree 文件，主工作区保持不变，任务结果给出保留分支和目录。
  **验证：** Fake Provider CLI/Runner 端到端场景。对应 AC1、AC6、AC7。

- [x] **C43 端到端干净任务清理**：隔离子 Agent 只读取并正常结束后，自动删除干净 Worktree。
  **验证：** Fake Provider 只读场景。对应 AC7。

- [x] **C44 README 示例有效**：文档中的 YAML 与角色 frontmatter 可被真实解析器加载。
  **验证：** 提取或复制示例到测试 fixture 执行解析。对应 AC10。

- [x] **C45 Worktree 专项测试通过**：所有新增 Worktree、初始化、清理和子 Agent 集成测试通过。
  **验证：** `python -m unittest tests.test_worktree_naming tests.test_worktree_manifest tests.test_worktree_git tests.test_worktree_initializer tests.test_worktree_manager tests.test_subagent_worktree -v`。

- [x] **C46 全量测试通过**：现有聊天、Provider、工具、权限、Hook、MCP、上下文、记忆、Slash Command、Skill 和子 Agent 行为无回归。
  **验证：** `python -m unittest discover -s tests -v`。对应 AC11。

- [x] **C47 编译检查通过**：源码和测试无语法错误。
  **验证：** `python -m compileall huicode tests`。

- [x] **C48 Diff 检查通过**：不存在尾随空格、冲突标记或空白错误。
  **验证：** `git diff --check`。

- [x] **C49 用户文件未受影响**：既有未跟踪文件未被删除或暂存。
  **验证：** 对比实施前后 `git status --short`，检查提交暂存清单。

- [x] **C50 验收与提交完成**：验收报告记录 C1-C49 的真实结果；发生真实返工时已更新踩坑文档；仅本章文件进入 Git 提交。
  **验证：** 检查 `acceptance_report.md`、`docs/mew-spec-pitfalls.md` 条件更新、`git diff --cached --name-only` 和最终提交。
